# GUIDE

Purpose: reference guides and validation notes for the original source.

Key files:

- `VALIDATION_REPORT.md` - explains which guide content is reliable and which examples are stale or wrong.
- `DEVELOPER_INDEX.md` - high-level orientation, useful but not fully implementation-safe.
- `BUILDING_GUIDE.md` - extension guide, useful only with validation caveats.

Rule: do not rely on guide examples blindly. The original source and `DATA/canonical-manifest.json` are stronger authorities.
